## Description

Do your products consist of several components yet you are selling them separately? Our Bundle Products plugin solves this! It enables you to select the specific components that, when combined, make up a single product. You can select which product to sell, while simultaneously showcasing which separate components are included in it. We even made it possible for you to select the quantity for each component. For example, for a table, the page would show that four table legs are included in the product.

By assigning products to a product via the administration you can sell multiple products by simply listing one.

## Get started with the plugin:

-   Download the plugin from the Community Store
-   Install and activate the plugin in your Shopware 6 installation via the extension manager and open the plugin configuration
-   In the plugin configuration you can configure how the plugin behaves. Matters like how the stock is managed can be configured here
-   Once you are satisfied with the configuration, navigate to "Catalogues > Products" and open a product of your choice.
-   Configure which products are connected to the bundle via the dropdown in the "Bundle product configuration" section.
-   You can specify a quantity and optional comment for each individual bundle item to your preference
-   Check the box "Show products on storefront" if you like the contents of the bundle to appear on the storefront.
-   Check the box "Show bundle item prices on storefront" if you like the prices of the items inside the bundle to appear on the storefront.
-   Check the box "Offer bundle optionlly" if you would like the customer to be able to just add the bundle product to the cart and optionally add the contents of the bundle as well.
-   Save the product to commit the changes made to the bundle
